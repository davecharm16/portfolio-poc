## Story

**As a** portfolio visitor,
**I want** the site to have a unique, professionally designed visual system with consistent colors and typography,
**so that** the portfolio demonstrates both technical skill and design sensibility while remaining accessible across light and dark modes.

---

## Acceptance Criteria

1. **shadcn/ui CLI installed and configured** with components.json created for the monorepo structure
2. **Custom color palette defined** for light and dark modes with primary, secondary, accent, and neutral color scales
3. **WCAG 2.1 AA contrast compliance verified** using automated color contrast checker (4.5:1 for normal text, 3:1 for large text)
4. **Complete typography scale established** with Inter font including responsive heading sizes (h1-h6), body text, captions, and labels
5. **Tailwind configuration updated** with new design tokens (colors, typography, spacing) in tailwind.config.js
6. **Theme switching tested** between light and dark modes with no visual glitches, utilizing existing ThemeContext

### Color System Architecture

**CSS Variables Pattern:**
[Source: docs/architecture.md#10-frontend-architecture]

shadcn/ui uses HSL color format with CSS variables:
```css
--primary: <hue> <saturation>% <lightness>%;
--primary-foreground: <hue> <saturation>% <lightness>%;
```

**Recommended Color Structure:**
- Primary colors: For main CTAs, brand identity
- Secondary colors: For supporting elements
- Accent colors: For highlights, interactive elements
- Neutral/Gray scale: For backgrounds, borders, text
- Destructive colors: For errors, warnings
- Muted colors: For subtle backgrounds

**Dark Mode Implementation:**
Use `.dark` class selector to override CSS variables for dark mode variants.

### Typography System Architecture

**Recommended Type Scale:**
[Source: docs/architecture.md#17-coding-standards]

```
h1: 3xl-4xl (mobile-desktop)
h2: 2xl-3xl
h3: xl-2xl
h4: lg-xl
h5: base-lg
h6: base
body: base
small: sm
caption: xs
```

**Line Height Guidelines:**
- Headings: 1.2-1.3 (tighter for impact)
- Body text: 1.5-1.6 (better readability)
- Small text: 1.4

**Font Weight Scale:**
- Regular: 400 (body text)
- Medium: 500 (subheadings, labels)
- Semibold: 600 (headings)
- Bold: 700 (emphasis, h1-h2)

### WCAG Compliance Verification

**Tools to Use:**
- WebAIM Contrast Checker: https://webaim.org/resources/contrastchecker/
- Chrome DevTools Lighthouse: Accessibility audit
- axe DevTools browser extension (optional)

**Minimum Contrast Ratios:**
- Normal text (< 18pt): 4.5:1
- Large text (≥ 18pt or 14pt bold): 3:1
- UI components and graphics: 3:1

**Verification Process:**
1. Test all primary text on background combinations
2. Test all interactive element states (default, hover, focus)
3. Test both light and dark mode variants
4. Document contrast ratios in color palette documentation
