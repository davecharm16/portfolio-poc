# Story 01.01: Scroll Animations & Mobile Navigation

## Status
InProgress

## Story
**As a** portfolio visitor,
**I want** smooth scroll animations and mobile-friendly navigation,
**so that** I have an engaging and accessible experience on all devices

## Acceptance Criteria
1. Sections animate into view as user scrolls down the page
2. Animations trigger when elements enter viewport (not on page load for off-screen content)
3. Header includes a hamburger menu on mobile/tablet breakpoints
4. Mobile menu opens/closes smoothly with animations
5. Mobile menu closes when a nav link is clicked
6. Animations are smooth and don't cause layout shift
7. Scroll animations work consistently across browsers

### Technical Approach
**Scroll Animations:**
- Use `react-intersection-observer` for scroll detection (lighter than framer-motion for this use case)
- Create a reusable `<ScrollReveal>` component that wraps content
- Use CSS animations defined in Tailwind config (already have fade-in, slide-in)
- Add variants: fade-up, fade-down, fade-left, fade-right
- Respect `prefers-reduced-motion` media query

**Mobile Navigation:**
- Use React state for menu open/close
- Hamburger icon: Use lucide-react `Menu` and `X` icons
- Mobile menu: Fixed position, full-height overlay
- Animation: Slide in from right with backdrop fade-in
- Breakpoint: Show hamburger below 768px (md breakpoint)
- Close on: Link click, backdrop click, escape key

### Testing
**Manual Testing:**
- Scroll through page and verify all sections animate
- Test on mobile viewport (375px, 414px, 768px)
- Test hamburger menu open/close
- Test menu closes on link click
- Test scroll animations at different speeds
- Verify reduced motion preference is respected

**Accessibility:**
- Hamburger button has proper aria-label
- Mobile menu has aria-expanded state
- Focus management when menu opens/closes
- Keyboard navigation works (Escape to close, Tab through links)
